# 3D 引擎

## 当前实现

浏览器客户端使用原生 WebGL：

- 真实透视/正交投影矩阵
- 轨道旋转和滚轮缩放
- 前/后视切换
- 依据机架高度、设备 `start_u` 和 `rack_units` 定位几何
- 依据设备类型着色
- 设备投影拾取与对象检查器
- 依据 `PathwaySegment.coordinates` 绘制选中线缆路线
- 仅渲染所选链路，避免永久绘制所有线缆

模型来自 API 持久化数据，而不是静态截图或硬编码画面。

## 当前限制

- 不是完整场景编辑器；不能拖放机架或设备并保存
- 无 GLTF/GLB/BIM 适配器
- 无大场景 LOD、实例化、分区或 Web Worker
- 未在真实浏览器矩阵上运行 Playwright/WebGL 截图回归
- 无移动设备 GPU 性能基准
- 路径使用折线，不是样条/束化几何

因此本模块不能按完整主范围标记 100%。
